## 📁 How to Run Locally

If you would like to explore the codebase or run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/fayaz921/fayaz-portfolio.git](https://github.com/fayaz921/fayaz-portfolio.git)

```

2. **Navigate into the directory:**
```bash
cd fayaz-portfolio

```


3. **Install dependencies:**
```bash
npm install

```


4. **Run the development server:**
```bash
npm run dev

```


*Open the local URL provided in your terminal (usually `http://localhost:5173`) to view the site.*
